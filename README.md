# Supply Chain Logistics & Parcel Tracker

A Python implementation of an audit-backed shipment tracking system that logs physical parcel updates with SHA-256 cryptographic checkpoints.

## Key Features
- **Immutable Log History:** Calculates event hashes for every checkpoint to detect tampered logs.
- **State Tracking:** Controls package lifecycle transitions from creation to delivery.
- **JSON Export:** Provides machine-readable tracking outputs for API consumption.
